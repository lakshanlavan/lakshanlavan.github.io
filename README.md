# Lakshan L. — Personal Portfolio

Personal portfolio showcasing engineering, embedded systems, AI, robotics, IoT
and research projects, from autonomous crop-field navigation and edge-AI
computer vision to custom PCB and controller design.

🌐 **Live Website:** https://lakshanlavan.github.io/lakshan.github.io/

## About

This repository contains the source code and portfolio materials for the
personal website of Lakshan L. It brings together research work in
agricultural robotics and computer vision alongside commercial embedded and
edge-AI systems built for real deployments.

## Technology

Built with React and Vite, and deployed through GitHub Actions and GitHub
Pages. Routing is handled client-side, and all media is served as static
assets from the site itself.

### Local development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

The production deployment builds with a repository sub-path base; local
development and preview continue to serve from `/`.
